CONCEPT

私たちの想い

「全ての利用者様が、
いつまでも自分の足で
歩き続ける」

年齢を重ねても、行きたい場所へ自分の足で出かけたい。家族と一緒に歩きたい。そんな当たり前の毎日を、少しでも長く続けていただくために私たちはここにいます。

専門職がお一人おひとりの身体の状態を丁寧に評価し、無理なく続けられるリハビリをご提案。小さな「できた」を積み重ねながら、前向きな毎日を一緒につくっていきます。

FEATURES

大船西口が選ばれる理由

専門職の知識と最新の設備、そして一人ひとりに目が届く環境。「通ってよかった」と思っていただける4つのこだわりです。

01

専門職による機能訓練

理学療法士・あん摩マッサージ指圧師が、お一人おひとりの身体の状態を評価。生活の中の「困りごと」や目標に合わせて、個別の機能訓練プログラムを作成します。

  • 理学療法士
  • あん摩マッサージ指圧師
  • 個別計画
02

最新のリハビリマシン

身体への負担が少なく、ご高齢の方でも安全に使えるリハビリマシンを導入。筋力・バランス・柔軟性を効率よく高め、転倒しにくい身体づくりをサポートします。

  • 筋力アップ
  • バランス
  • 転倒予防
03

定員18名の少人数制

スタッフの目が行き届く少人数制。その日の体調や気分に合わせて、きめ細かく内容を調整します。初めての方も、運動が久しぶりの方も安心してご参加いただけます。

  • きめ細かな対応
  • アットホーム
04

午後3時間の短時間型

食事・入浴のない、リハビリに特化した短時間型。午前中はご自宅でゆっくり過ごし、午後に集中して身体を動かせます。「一日型のデイはまだ早い」と感じる方にも。

  • 13:30〜16:30
  • 送迎付き
PROGRAM

リハビリプログラム

目的に合わせて組み合わせる、4つのプログラム。カードにカーソルを合わせると詳しい内容をご覧いただけます。

MACHINE

マシントレーニング

負荷を細かく調整できるマシンで、立ち上がりや歩行に必要な下肢・体幹の筋力を安全に鍛えます。

CONDITIONING

マッサージ・ストレッチ

あん摩マッサージ指圧師が筋肉のこわばりをほぐし、関節の動きをなめらかに。運動の効果を高めます。

WALKING

歩行・バランス訓練

理学療法士が歩き方をチェック。段差や方向転換など、生活の場面を想定した練習で転倒を予防します。

EXERCISE

集団体操

音楽に合わせて全身をほぐす体操。皆さんと一緒に楽しく身体を動かし、自然と笑顔が生まれます。
